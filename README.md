# Finance Support Interface Demo

A responsive HTML/CSS proof of concept independently built by Sahil Malhotra to make product support easy to discover in a finance software interface. The page demonstrates layout, navigation, feature-card presentation and a support entry point using fictional text and sample figures.

## Implemented scope

- Static HTML and responsive CSS.
- Navigation, hero/dashboard preview, information cards and demo scope.
- Static Vercel hosting configuration.

No financial backend, account authentication, live AI, customer data or production chat widget is included. The original external Voiceflow production integration is removed from this prepared copy. This source does not verify the remote agent's implementation or performance.

## Preview locally

Open `index.html` in a browser, or serve this directory with a local static server.
